# TaskFlow | Gestión de tareas

Aplicación web para organizar tareas personales de forma sencilla y visual. El proyecto presenta un panel principal donde se pueden agregar tareas y consultar rápidamente el estado general de la lista.

## Descripción

**TaskFlow** es una aplicación de gestión de tareas desarrollada con tecnologías web básicas. Su objetivo es facilitar la organización de actividades pendientes mediante una interfaz clara, moderna y fácil de utilizar.

La pantalla principal incluye un resumen con:

* Total de tareas.
* Tareas pendientes.
* Tareas completadas.
* Porcentaje de progreso.
* Formulario para agregar nuevas tareas.

## Características

* Agregar nuevas tareas.
* Visualizar las tareas registradas.
* Identificar tareas pendientes.
* Identificar tareas completadas.
* Mostrar el progreso de las tareas.
* Interfaz moderna con tema oscuro.
* Organización del proyecto en HTML, CSS y JavaScript.

## Tecnologías utilizadas

* **HTML5** — estructura de la aplicación.
* **CSS3** — estilos y diseño visual.
* **JavaScript** — lógica e interacción de la aplicación.

### Ejecutar

Abre `index.html` en un navegador web.

También puedes utilizar **Visual Studio Code** con la extensión **Live Server** durante el desarrollo.

## Uso

1. Abre la aplicación.
2. Escribe la descripción de una nueva tarea.
3. Presiona **Agregar tarea**.
4. Revisa las tareas registradas.
5. Actualiza el estado de las tareas conforme avances.
6. Consulta el porcentaje de progreso.

## Objetivo del proyecto

Este proyecto fue desarrollado como una práctica de desarrollo web frontend para aplicar conocimientos de:

* HTML5.
* CSS3.
* JavaScript.
* Manipulación del DOM.
* Eventos e interacción con el usuario.
* Organización de archivos de un proyecto web.
